# NeuroBrand — сайт

Статический сайт агентства NeuroBrand: AI-автоматизация и маркетинговое продвижение.

## Структура
- `index.html` — главная
- `ai.html` — AI и автоматизация (флагманский оффер + демо чат-бота)
- `marketing.html` — маркетинговые услуги
- `cases.html` — кейсы и портфолио
- `about.html` — команда
- `contact.html` — заявка (раздельные формы под направления)
- `css/style.css`, `js/*.js` — стили и логика

## Локальный запуск
Просто открой `index.html` в браузере, либо:
```
python3 -m http.server 8000
```
и зайди на `http://localhost:8000`.

## Известные ограничения (до продакшна)
- Отправка форм не подключена к CRM/почте/Telegram — сейчас демо-подтверждение.
- Казахский перевод (`js/i18n.js`) черновой, нужна вычитка носителем языка.
- Разделы кейсов — placeholder, нужны реальные цифры/отзывы клиентов.
